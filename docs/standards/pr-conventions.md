# Pull Request Conventions

**Scope:** All pull requests in this repository.  
**Keywords:** RFC 2119 (SHALL / SHOULD / MAY / SHALL NOT / SHOULD NOT)

---

## PR-01 — PR title length

**Rule:** The PR title SHALL be 70 characters or fewer.

**Rationale:** Matches GitHub's list view width; longer titles are truncated and lose context.

```
# Correct (44 chars)
Add AI coding support: CLAUDE.md and standards

# Incorrect (82 chars)
Add AI coding support infrastructure including CLAUDE.md, VS Code config, and standards docs
```

---

## PR-02 — Summary section

**Rule:** The PR body SHALL include a `## Summary` section with bullet points describing what changed and why.

```markdown
## Summary

- Add `CLAUDE.md` with project intelligence for AI coding assistants
- Add `.vscode/` configuration for formatting, tasks, and extensions
- Add `docs/standards/` covering C#, git, and PR conventions
```

---

## PR-03 — Test plan section

**Rule:** The PR body SHALL include a `## Test plan` section with a markdown checklist of steps taken (or to be taken) to verify the change.

```markdown
## Test plan

- [x] `dotnet build 5coy-archive.sln` succeeds with 0 errors
- [x] `dotnet test 5coy-archive.sln` — all tests pass
- [x] Site loads at `http://localhost:5000` with no console errors
- [ ] Dev container opens successfully in local Docker
```

---

## PR-04 — Feature branches target `dev`, not `master`

**Rule:** PRs from feature or fix branches SHALL target `dev`. PRs SHALL NOT open directly from a feature branch to `master`.

**Rationale:** `master` receives only integration PRs from `dev` and is the production deployment trigger. Bypassing `dev` skips integration testing.

```
# Correct flow
feature/48-ai-coding-support → dev   ✓
dev → master                          ✓

# Incorrect
feature/48-ai-coding-support → master  ✗
```

---

## PR-05 — Link to the relevant issue

**Rule:** PRs SHALL reference the relevant GitHub issue. SHOULD use `Closes #N` syntax so the issue is automatically closed on merge.

```markdown
## Summary

Closes #48

- Add `CLAUDE.md`…
```

If the PR only partially addresses an issue, use `Relates to #N` or `See #N` instead of `Closes`.

---

## PR-06 — AI-generated PR bodies

**Rule:** PR descriptions substantially generated by an AI assistant SHOULD be marked with a footer identifying the tool.

```markdown
🤖 Generated with [Claude Code](https://claude.com/claude-code)
```

**Rationale:** Transparency about AI-assisted authorship; allows reviewers to apply appropriate scrutiny to the description's accuracy.
